# 实验流程 v0.2：STM32 与 ESP32 双向 ACK 通信

## 1. 目标

在 v0.1 的 STM32 -> ESP32 单向心跳基础上，增加 ESP32 ACK 回复和 STM32 超时判断，验证双向串口链路。

## 2. 接线

两块板分别使用电脑 USB 供电，只连接三根信号线：

| STM32F103C8T6 | ESP32-WROOM-32 |
|---|---|
| PA2（USART2_TX） | GPIO16（RX2） |
| PA3（USART2_RX） | GPIO17（TX2） |
| GND | GND |

不要互接两块板的 3.3V 或 5V 电源脚。

## 3. 通信协议（v0.2 验证版）

| 方向 | 帧内容 | 周期/触发 |
|---|---|---|
| STM32 -> ESP32 | `GW,HEARTBEAT\r\n` | 每 1 秒 |
| ESP32 -> STM32 | `ESP,ACK\r\n` | 收到任意 STM32 数据后 |

## 4. 预期现象

- VS Code 的 ESP-IDF Monitor 每秒打印：`STM32 RX: GW,HEARTBEAT`
- 随后打印：`ACK TX: ESP,ACK`
- STM32 在 3 秒内收到 ACK 时，板载 LED 慢闪（约 1 秒一次）；超时后快闪（约 250 ms 一次）。
- 若 OLED 已接入且初始化成功，最后一行显示 `NET: ESP ACK`。

## 5. 烧录顺序

1. 在 Keil 按 F7 编译 STM32 工程，确认 `0 Error(s)` 后按 F8 下载。
2. 在 VS Code 打开 `esp32_gateway`，运行 **ESP-IDF: Build, Flash and Monitor your Device**。
3. 若 ESP32 不能进入下载模式，按住 BOOT 后开始烧录，出现写入进度后松开。

## 6. 排障

- ESP32 只打印 `Gateway UART ready`：优先检查 PA2 是否接 GPIO16、GND 是否共地、STM32 是否下载了最新固件。
- ESP32 能收到心跳但 STM32 始终快闪：检查 PA3 是否接 GPIO17；不要接到 ESP32 的 RX0/TX0。
- USB 供电不稳定：两块板分别接笔记本 USB，信号线只保留 TX/RX/GND。
