# 工业网关项目面试深挖题库

使用方式：先口述，再结合源码指出函数和变量，最后给出实测证据。不会的功能应明确区分“代码构建通过”和“实机验证通过”。

## 1. 项目真实性与总体架构

1. 用两分钟介绍项目解决的问题、数据流、当前完成度和你亲自负责的部分。
2. 为什么采用 STM32 + ESP32 双控制器，而不是只用一颗 ESP32？代价是什么？
3. 从传感器到 MQTT Broker，一条数据依次经过哪些硬件、任务、协议帧和函数？
4. 哪些功能已经实机验证，哪些只是代码及构建通过？证据是什么？
5. 如果删掉 ESP32、改用带网络能力的 MCU，架构会怎样变化？

## 2. STM32 FreeRTOS

1. 五个任务的职责、周期、优先级和栈大小分别是什么？为什么这样分配？
2. `App_Init()`、`xTaskCreate()`、`App_StartScheduler()`分别做什么？
3. `LinkContext`（通信链路上下文）为什么是任务局部变量，而 `GatewayStatus`（网关共享状态）是全局变量？
4. `s_status_mutex`（共享状态互斥量）和 `s_i2c_mutex`（I2C总线互斥量）分别保护什么？
5. 低优先级显示任务持有I2C互斥量时，高优先级传感器任务申请该锁，会发生什么？什么是优先级继承？
6. 为什么使用 `vTaskDelayUntil()`？任务执行时间超过周期时会发生什么？
7. 任务栈的单位为什么是 word？怎样证明当前栈大小足够？
8. `heap_4.c` 的特点是什么？任务创建失败和栈溢出分别怎样处理？

## 3. UART心跳、ACK与重传

1. `GW,HB,<seq>` 和 `ESP,ACK,<seq>` 的完整往返函数链是什么？
2. `next_seq`（下一个序号）和 `pending_seq`（待确认序号）为什么不能合并？
3. 为什么重传必须使用相同序号？首次发送加三次重传总共发送几次？
4. ACK被接受必须满足哪些条件？迟到ACK、错误序号和重复ACK分别怎样处理？
5. 16位序号回绕时怎样处理？为什么跳过0？
6. 当前ACK能证明UART链路正常，为什么不能证明MQTT已经上报成功？
7. ASCII行协议为什么使用 `\r\n`？`\n`、`\0`分别承担什么职责？
8. `sscanf()`解析有什么宽松匹配、范围和代码体积风险？产品化时怎样改进？
9. 心跳有ACK，但 `GW,DATA` 和 `GW,MB` 没有ACK或CRC，可能带来什么问题？

## 4. UART中断与环形缓冲区

1. 为什么从任务轮询 `HAL_UART_Receive()` 改为 `HAL_UART_Receive_IT()`？
2. `HAL_UART_RxCpltCallback()`、`s_esp_rx_ring`（ESP接收环形缓冲区）、`EspRxPop()`和 `PollEspUart()`各自负责什么？
3. `head`（写索引）和 `tail`（读索引）相等表示什么？怎样判断缓冲区满？为什么会浪费一个槽位？
4. 缓冲区满时当前实现怎样处理？为什么应增加溢出计数？
5. 中断回调里为什么不执行 `sscanf()`、日志或OLED刷新？
6. `volatile`解决了什么，不能解决什么？单生产者单消费者模型为什么适合这里？
7. 如果UART持续高速输入，64字节环形缓冲区是否足够？怎样计算和验证？
8. 为什么没有直接使用DMA空闲线接收？中断、DMA和轮询如何选型？

## 5. I2C、传感器与OLED

1. OLED、AHT20、INA219为什么能共用I2C1？什么情况下应使用I2C2？
2. 三个设备的地址和功能分别是什么？I2C地址为什么在HAL调用中左移一位？
3. `SensorData`（传感器数据）为什么使用定点数而不是浮点数？
4. AHT20读取中的 `HAL_Delay(80)` 对任务调度和I2C互斥量有什么影响？
5. `SSD1306_WriteString()`与 `SSD1306_Update()`有什么区别？刷新一帧大约占用多少总线时间？
6. 某个设备拉低SDA导致I2C总线卡死时，系统怎样表现，如何恢复？

## 6. RS485与Modbus RTU

1. UART、RS485和Modbus分别属于哪一层？MAX3485的DE和 `/RE` 有什么作用？
2. 功能码03请求帧和正常响应帧分别有哪些字段？
3. Modbus CRC16怎样计算，为什么在线路上低字节先发送？
4. 异常响应怎样识别？地址、功能码、字节数和CRC分别为什么要检查？
5. `HAL_UART_Transmit()`返回后再切换为接收模式是否安全？依据是什么？
6. 当前阻塞式UART接收最长会占用任务多久？会不会影响其他任务？
7. 没有真实从站寄存器表时，为什么不能把reg0直接解释成温度或转速？

## 7. ESP32、Wi-Fi与MQTT

1. ESP-IDF的 `app_main()` 与STM32的 `main()`有什么区别？
2. 为什么需要 `uart_driver_install()`、`uart_param_config()`和 `uart_set_pin()`？
3. `GatewayUartTask`怎样从驱动缓冲区拼接三类协议帧？
4. Wi-Fi事件回调和MQTT事件回调分别处理哪些状态变化？
5. 事件组中的 `WIFI_CONNECTED_BIT` 和 `MQTT_CONNECTED_BIT` 有什么作用？为什么不用普通全局布尔变量？
6. MQTT QoS 0和1有什么区别？项目为什么只允许0～1？
7. Last Will、retain、status topic分别解决什么问题？
8. Wi-Fi断开后怎样重连？MQTT客户端在尚未获得IP时启动会怎样？
9. cJSON对象和打印出的字符串分别由谁释放？遗漏释放会造成什么后果？
10. UART任务和事件回调共同访问最新遥测及发布标志时，是否存在并发风险？如何用队列或任务通知改进？

## 8. 看门狗、低功耗与可靠性

1. `TaskHealthMark()`、`WatchdogTask()`和IWDG怎样组成任务级健康监督？
2. 为什么不能让每个任务各自直接喂硬件看门狗？
3. 各任务健康截止时间为什么不同？IWDG约8秒超时与这些截止时间是什么关系？
4. 监督任务本身卡死会怎样？IWDG使用LSI带来什么误差？
5. `vApplicationIdleHook()`中的 `__WFI()`进入什么睡眠？什么中断会唤醒？
6. 为什么不直接使用STOP、Standby或ESP32 Deep-sleep？
7. ESP32任务看门狗与STM32 IWDG有什么区别？

## 9. 测试、故障注入与改进

1. 如何分别验证正常ACK、断线重传、复线恢复、错误序号和环形缓冲区溢出？
2. 编译0错误为什么不能证明硬件功能正确？
3. 如何测量任务周期、栈余量、CPU占用、I2C占用时间和UART丢帧率？
4. 如何安全验证STM32看门狗复位和ESP32任务看门狗？
5. 当前项目最可能出现的三个故障是什么？你会按什么顺序定位？
6. 如果再做一版，最优先改进哪三项，为什么？

## 10. C语言、HAL与FreeRTOS内存

1. `static`修饰文件内函数、函数局部变量和文件全局变量时分别有什么作用？
2. `extern UART_HandleTypeDef huart1`是定义还是声明？对象真正在哪里定义？
3. `snprintf()`的返回值是什么？为什么发送前要同时检查大于0和小于缓冲区大小？
4. `\n`、`\r`和`\0`分别有什么作用？为什么`\0`不通过UART发送？
5. `sscanf()`返回值是什么？为什么“成功提取8项”不等于传感器数据一定合理？
6. `volatile`能解决编译器优化问题，为什么不能代替互斥锁？
7. `xTaskCreate()`是动态创建还是静态创建？它从哪里分配TCB和任务栈？
8. `xTaskCreateStatic()`与`xTaskCreate()`有什么区别？当前项目为什么属于动态创建？
9. STM32项目中任务栈深度256为什么通常约等于1024字节？
10. FreeRTOS堆不足和任务栈溢出分别发生在什么阶段？表现有什么区别？
11. `heap_4.c`有什么特点？为什么当前项目运行中发生严重堆碎片的风险相对较低？
12. 什么是HardFault？它和项目主动调用的`Error_Handler()`有什么区别？
13. 发生HardFault时怎样利用PC、LR、CFSR和HFSR定位问题？
14. 阻塞式HAL函数是否意味着整个FreeRTOS系统都停止调度？为什么？

## 12. 现场故障与开放场景

1. 设备隔几小时随机重启，你会先收集哪些事实，而不是直接猜任务栈不足？
2. 如果复位原因为IWDG，你怎样区分任务卡死、死锁、HardFault和监督任务未运行？
3. 如果复位原因为POR/PDR，你会怎样验证是否存在电源瞬态跌落？
4. STM32显示ESP在线，但MQTTX收不到消息，故障范围怎样逐层缩小？
5. STM32一直收不到ACK，你会怎样区分接线错误、波特率错误、ESP任务未运行和缓冲区溢出？
6. 电脑Modbus从机能够收到请求，但STM32一直显示`MB:OFF`，说明哪一段已经正常，下一步查什么？
7. OLED显示正常，但传感器数据一直是占位符，你会怎样检查地址、供电、ready标志和I2C返回值？
8. AHT20运行中拔掉再插回，当前项目会怎样？为什么？
9. Wi-Fi已经获得IP，但MQTT一直连接不上，可能位于哪些层？
10. MQTT日志打印了有效message_id，但MQTTX没有消息，能否证明是谁丢失了消息？
11. QoS 1出现重复消息是否属于协议错误？订阅端应怎样处理？
12. 现场UART噪声造成一个字节丢失，当前文本协议可能怎样表现？如何重新同步？
13. 某任务长期占有I2C互斥锁，SUPERVISOR最终会怎样处理？为什么整机复位是最后手段？
14. 如果增加水泵、风扇或继电器后出现重启，你会怎样检查供电、续流、地线、NRST和软件复位原因？
15. 如果一个问题当天无法解决，你应怎样按“现象—假设—验证—结论—下一步”向团队汇报？
