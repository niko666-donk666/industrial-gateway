# 实验流程 v0.4：AHT20 与 INA219 本地采集

## 目标

在不影响既有 STM32 ↔ ESP32 UART 心跳链路的前提下，将 AHT20 温湿度传感器与 INA219 电压/电流传感器接入 STM32 的 I2C1 总线，并在 SSD1306 OLED 上显示采样结果。

本阶段只完成本地采集和显示；Wi-Fi/MQTT 上报在获得网络与 Broker 参数后单独实施和验证。

## I2C1 共线接线

OLED、AHT20、INA219 共用 STM32F103C8T6 的 I2C1：PB6（SCL）与 PB7（SDA）。所有模块必须共地，并全部使用 3.3 V 供电。

| 模块引脚 | STM32F103C8T6 |
|---|---|
| OLED VCC / AHT20 VCC / INA219 VCC | 3.3V |
| OLED GND / AHT20 GND / INA219 GND | GND |
| OLED SCL / AHT20 SCL / INA219 SCL | PB6（I2C1 SCL） |
| OLED SDA / AHT20 SDA / INA219 SDA | PB7（I2C1 SDA） |

INA219 的测量回路与 I2C 通信线不同：被测电源正极接 `VIN+`，负载正极接 `VIN-`；负载负极回到被测电源负极。不得将高电压或反接电压接到 INA219 的 VCC、SCL、SDA。

## 固件行为

| 器件 | 默认 I2C 7 位地址 | 行为 |
|---|---:|---|
| SSD1306 | `0x3C` | 保持既有状态页显示。 |
| AHT20 | `0x38` | 每 2 秒触发一次测量，换算温度与相对湿度。 |
| INA219 | `0x40` | 每 2 秒读取母线电压和分流电压，按模块常见的 0.1 Ω 分流电阻估算电流与功率。 |

OLED 状态页格式：

```text
IND GW V0.4
NET: ESP ONLINE
T:25.3C H:48.1
V:05.02 I:123MA
ACK:26 TO:0
```

- `T`：AHT20 温度；`H`：相对湿度。传感器未检测到时显示 `--`。
- `V`：INA219 母线电压；`I`：按 0.1 Ω 分流电阻计算的电流。若你的 INA219 模块分流电阻不同，需要调整 `App/Src/sensors.c` 的 `INA219_SHUNT_MILLIOHM`。
- `NET`、`ACK`、`TO`：沿用 v0.3 串口链路状态与统计。迁移 FreeRTOS 后标题实际显示为 `IND GW RTOS`。

## 验证步骤

1. 断电后完成上表接线，确认 I2C 模块 VCC 均接 3.3V，所有 GND 共地。
2. 在 Keil 打开 `MDK-ARM/industrial_gateway.uvprojx`，执行 F7 编译、F8 下载 STM32。
3. 上电后观察 OLED：AHT20 和 INA219 正常识别时，温湿度与电参量应替代 `--` 占位符并约每 2 秒刷新。
4. 改变环境温度或对 AHT20 呼气，确认 `T`/`H` 有合理变化；改变 INA219 负载，确认 `I` 与 `V` 相应变化。
5. 同时保持 ESP32 通信线连接，确认 OLED 第四行 `ACK` 持续增加且 `TO` 不异常增长。
