# 实验流程 v0.1：STM32 + OLED 网关启动

**项目**：工业设备远程运维与故障诊断终端  
**主控**：STM32F103C8T6（Blue Pill）  
**固件版本**：v0.1  
**目标**：完成 STM32 工程生成、App 模块集成、ST-Link 烧录，并验证本地状态显示基础能力。

## 1. 本阶段目标

1. STM32 运行在 72 MHz；
2. PC13 板载 LED 每 500 ms 翻转一次，作为程序心跳；
3. I2C1 驱动 OLED，显示网关启动与网络等待状态；
4. 预留 USART2 给 STM32 与 ESP32 的后续通信。

## 2. 硬件连接

### 2.1 ST-Link 下载接口

| ST-Link | STM32F103C8T6 | 用途 |
| --- | --- | --- |
| 3.3V | 3.3V | 供电 |
| GND | GND | 共地 |
| SWDIO | PA13 / SWDIO | 调试数据 |
| SWCLK | PA14 / SWCLK | 调试时钟 |

- BOOT0 跳帽保持在 `0`；
- 下载阶段只使用 ST-Link 的 3.3V 供电，避免同时给 STM32 Micro-USB 供电。

### 2.2 OLED（常见 SSD1306 I2C 四针模块）

| OLED | STM32F103C8T6 | CubeMX 外设 |
| --- | --- | --- |
| GND | GND | - |
| VCC | 3.3V | - |
| SCL | PB6 | I2C1_SCL |
| SDA | PB7 | I2C1_SDA |

## 3. CubeMX 配置

工程配置文件：`industrial_gateway.ioc`。

| 模块 | 配置 |
| --- | --- |
| 芯片 | STM32F103C8Tx |
| 时钟 | HSE 8 MHz，PLL ×9，SYSCLK 72 MHz |
| 调试 | Serial Wire（SWD） |
| LED | PC13，GPIO Output，标签 `HEARTBEAT_LED` |
| OLED | I2C1：PB6 / PB7 |
| ESP32 预留串口 | USART2：PA2(TX) / PA3(RX)，115200 bps |
| 工具链 | MDK-ARM V5（Keil） |

在 CubeMX 打开 `.ioc` 后点击 **Generate Code**，生成 Keil 工程。

## 4. Keil 集成 App 模块

### 4.1 新建文件分组

在 `Project -> Manage Project Items...` 中新建分组 `APP`，将以下文件加入：

```text
App/Src/app_main.c
App/Src/ssd1306.c
```

### 4.2 增加头文件路径

在 `Project -> Options for Target -> C/C++ -> Include Paths` 增加：

```text
..\App\Inc
```

### 4.3 修改 main.c

仅在 CubeMX 的 `USER CODE` 区域添加代码，以便今后重新生成工程时保留修改。

头文件区：

```c
/* USER CODE BEGIN Includes */
#include "app_main.h"
/* USER CODE END Includes */
```

在以下初始化完成后调用 App 初始化：

```c
MX_GPIO_Init();
MX_I2C1_Init();
MX_USART2_UART_Init();

/* USER CODE BEGIN 2 */
App_Init();
/* USER CODE END 2 */
```

在主循环中调用：

```c
while (1)
{
  /* USER CODE BEGIN WHILE */
  App_RunOnce();
  /* USER CODE END WHILE */
}
```

## 5. 编译与烧录

1. 按 `F7` 编译，期望结果为 `0 Error(s)`；
2. `Options for Target -> Debug` 选择 `ST-Link Debugger`；
3. 在 `Settings` 中将 Port 设为 `SW`；
4. 在 `Utilities` 中勾选 `Use Debug Driver` 并选择 `ST-Link Debugger`；
5. 确认 Flash Download 存在 STM32F103C8 Flash 算法；
6. 按 `F8` 或点击 `Load` 下载。

成功标志：Keil 输出 `Flash Load finished`。

## 7. 常见问题

- **`app_main.h: No such file`**：检查 Include Paths 是否含 `..\App\Inc`。
- **ST-Link 无法连接目标板**：复核 GND、3.3V、SWDIO、SWCLK；确认 BOOT0 在 0。
- **OLED 空白**：先检查 VCC 是否接 3.3V、SCL/SDA 是否接 PB6/PB7；当前驱动默认 OLED I2C 地址为 `0x3C`。
- **LED 亮灭逻辑反向**：Blue Pill 板载 LED 通常为低电平点亮，属于正常现象。
